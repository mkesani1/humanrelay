How Relay thinks

Every complex question is a tree of binaries. Relay finds the smallest tree that gets the answer.

1
Negotiate
Relay works with your agent to understand the question. If it's already a binary, it routes directly. If not, Relay proposes a decomposition.
2
Decompose
Complex questions split into independent binaries. Independent binaries run in parallel across multiple workers. Dependent ones run in sequence.
3
Reassemble
Binary answers compose into a final response with reasoning. The full trace — every binary, every answer — is returned for your agent's learning loop.

Frequently Asked Questions

Everything you need to know about HumanRelay, from integration to pricing.

What is HumanRelay?
HumanRelay is a human-in-the-loop API that gives AI agents access to expert human judgment on demand. It provides five core primitives — Classify, Judge, Extract, Escalate, and Resolve — accessible via a single REST API or MCP server.
How is HumanRelay different from Scale AI or Labelbox?
Unlike traditional annotation platforms built for batch data labeling workflows, HumanRelay is designed specifically for AI agents operating in real time. It offers API-first access, managed expert workers (not crowdsourced), and sub-minute response times for escalation workflows.
What types of tasks can HumanRelay handle?
HumanRelay handles a wide range of tasks including content moderation, RLHF evaluation, data annotation, complex judgment calls, robotics HITL, regulatory compliance review, and more. See our Service Catalogue for concrete examples.
Who are your human experts?
Our workforce includes 1,200+ managed professionals across three tiers: trained annotators for high-volume tasks, STEM-educated engineers for AI evaluation, and credentialed domain specialists (lawyers, doctors, financial analysts) for high-stakes decisions. All workers are vetted, trained, and managed — not crowdsourced.
